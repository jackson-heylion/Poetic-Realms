## 《江雪》3D 场景 river-snow（PR #15）

- 新增 `scenes/jiangxue/river-snow.html`：WebGL1 + 原生 JS 单文件，484 行，6 个 draw call。
- 地形：184×236 扭曲网格高度场（近密远疏，±520 × 近 1540 米），构建期烘焙顶点遮蔽（1 格 / 4 格邻域高差）。
- 雾：天空函数按距离 + 高度双层混合，40 米内不起雾、200 米外山谷沉入雾海，形成「峰出雾」的千山层次。

- 修 `scripts/test-agent-prompt.mjs` 写死 `scenes.length === 2` 的断言（第二版出现即失败），改为按基准条数 +1 推导并校验路径唯一。

### 复用经验

- 该仓库 `scripts/validate.mjs` 只把**第一个** `<script>` 块丢进 `vm.Script` 做语法检查，单文件内多 script 要注意顺序。
- 场景 HTML 需 `.embed` 类在 iframe 中隐藏自带 HUD（gallery 直接嵌 `scenes/...`）。
- 相机用「固定视点 + yaw/pitch 头部旋转 + 沿视线推拉」比绕远景 pivot 轨道更稳，避免拖动时相机穿进山体。
- 高度场做雪山时，纯坡度阈值分岩石会得到「墨点」；改成烘焙 AO + 风蚀色差更接近真实雪山的体块感。

### 实测

- 桌面 1600×900 @DPR1：中位 16.7ms（60FPS）；iPhone13 视口（DPR 3 → 画布 507×863）：60FPS；首帧 ~430ms。
- 环境：macOS + Chromium(ANGLE Metal) + AMD Radeon Pro 5500M，非真机。

## 船与人物重做（PR #18）

- 用户否掉了「船、人」：原实现是 CapsuleGeometry 压扁的黑胶囊 + 圆锥/球/圆锥拼的渔翁。
- 换参数化敞口船身 hullPt(u,a)：舷弧（艏高艉低）+ 圆舭剖面 + 舷缘 + 两端封头 + 舱底铺板 + 横梁 + 自建半圆拱竹篷。两篇共用同一套几何。
- 蓑衣 = 深色实体 + 两层参差草壳（下摆随机锯齿）+ 亮草茎；斗笠用倒序 LatheGeometry（点位从檐到顶，否则法线朝内、正面被剔）。
- **关键坑**：倒影若用 depthTest:false 的镜像克隆，会把镜像的舱板/横梁叠到船身上，像船里竖着几块板。正解是水面 depthWrite:false + 船体 clippingPlanes(y>0) + 倒影 clippingPlanes(y<0) 且保留深度测试。
- 另一个坑：水面 y=0 是实体平面，会直接横穿船舱，舱里「灌水」。要把舱底板抬到吃水线以上。
- 江雪机位 3.05→2.02 m、视场 42°，船才进到下三分之一；竖屏两篇都要单独给机位，否则船被裁。
