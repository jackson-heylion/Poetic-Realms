## 踩坑（有跨会话价值）

- **内联 vendor JS 绝不能用 `String.prototype.replace(pattern, bigString)`**：three.min.js 内含有 `$&` / `$'` 等序列，会被当作替换语义展开，破坏 `console.warn` 那一行并导致 `Unexpected token '&'`，且 `validate.mjs` 只检查已登记到 `poems.json` 的场景路径，未登记时不会报错。用 `s.replace(pattern, () => bigString)` 或字符串切片拼接；内联后单独用 `vm.Script` 编译每段 inline script 再跑浏览器。
- `gh` 不在 PATH，绝对路径 `/usr/local/bin/gh`；账号 `jackson-heylion` 对该仓库有 ADMIN 权限，可 push 分支并建 PR。
- 临时 npm 包装在 `.tmp-pw/`（`npm install playwright-core`，不下载浏览器，用本机 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`），`output/` 与 `.tmp-pw/` 均不提交。
